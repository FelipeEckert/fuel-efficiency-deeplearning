# Vehicle scenario browser QA

Tested the local Streamlit app in headless installed Chrome with a fresh isolated context, 1440 × 900 viewport, English locale, and synthetic inputs. Used the existing server on port 8501. The runnable harness is qa-deep-vehicle.py and the browser log is qa-deep-vehicle.txt in this directory.

| Case | Steps | Expected | Observed |
| --- | --- | --- | --- |
| Duplicate names | Save "  Urban test  " at defaults. Apply **10 % lighter**, save "Urban test", then save "urban test". | Preserve existing rows and keep identical names distinguishable. | Whitespace was stripped. The exact repeat became **Urban test (2)**. The case variant stayed **urban test**. All three remained distinct in the list and Excel. The baseline was 1495 kg and 1.93964957 MJ/km. Each lighter row was 1345.5 kg and 1.86276705 MJ/km. New coverage. |
| Internal navigation | With three saved rows and −10% selected, type and commit **Unsaved draft** as the scenario name, visit Comparison, return to Vehicle, and export again. | Saved scenarios remain available. For continuity, preserve the working adjustment and name. | The export contained identical cells before and after navigation. The active adjustment reset from −10% to 0%, as in PR #37 F05. The draft name reset to **Scenario 4**, extending that finding. An attempted draft mass edit did not show as committed in the pre-navigation summary, so this run cannot establish whether a committed mass edit survives internal navigation. |
| Invalid adjustment and recovery | Set curb mass to 301 kg, apply **10 % lighter**, save **Rejected adjustment**, then **Back to original**, set 1500 kg, apply the preset and save **Recovered valid**. | An invalid adjustment cannot be saved. After correction, save the adjusted inputs and displayed prediction. | 270.9 kg triggered the 300 kg minimum. Save remained available and the export silently recorded 301 kg and 1.72547642 MJ/km, consistent with PR #37 F03. After correction, the export recorded 1350 kg and 1.85855911 MJ/km, matching the valid adjusted state. |
| Remove the baseline | Remove the first of five rows, then export again. | Promote the next saved row and retain the other rows and values. | **Urban test (2)** became the baseline. The export contained the four remaining rows in order and kept their mass and combined predictions. New coverage. |
| Full browser reload | Reload Vehicle after removing the baseline and exporting. | If state lives only for the browser session, make the persistence limit clear where the user saves. | All four rows disappeared and **Export scenarios (Excel)** was no longer available. Mass reset from 1500 to 1495 kg and adjustment from −10% to 0%. This extends PR #37 F05, whose full reload covered Portfolio. The previously downloaded workbook remained readable. |

The initial test harness timed out while the app was still running and was retried with a longer wait. This pass does not quantify cold-start latency. The name checks use Enter to commit the textbox. Browser/platform coverage is limited to the stated configuration.

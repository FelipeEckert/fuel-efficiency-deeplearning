# Data

```
data/
  raw/        original spreadsheets (do not edit) + complemento_baterias.csv
  processed/  pbev_2026_limpo.csv, generated by eficiencia.dados (command below)
```

`raw/complemento_baterias.csv`: battery capacity researched in public sources (Nov 2026) for the vehicles where PBEV does not report it. One row per brand + model + power + mass, with the source link, capacity type and confidence (alta / media / baixa / sem_fonte, that is high / medium / low / no source). It only fills gaps and never overwrites PBEV.

To regenerate: `uv run eficiencia-limpar`

## Source

The **"Dados de Entrada"** sheet of `PED - PLANILHA DE ENTRADA DE DADOS PBEV 2026_05-05-2026.xlsm`. Its 844 versions become **510 unique homologations** (one row per test).

The spreadsheet `ESPECIFICAÇÃO TÉCNICA - FEVEREIRO DE 2026.XLSM` is not used for now.

## Cleaning rules

| Problem | What was done |
|---|---|
| Powertrain written in many ways ("Hibrido", "Plug-In", "Gasolina"…) | standardized to Combustão / Híbrido / Plug-in / Elétrico (combustion, hybrid, plug-in, electric) |
| Brand with extra spaces or different casing; "VW", "CAOACHANGAN" | uppercase, no extra spaces; VOLKSWAGEN, CAOA CHANGAN |
| Power in 200+ formats (kW, cv, "176 cv (G) e 176 cv (E)", "120 + 10", "150/110") | converted to kW. Flex: the higher of the gasoline and ethanol values. Mercedes "A + B" = engine + electric motor. JAC "cv/kW". Number without a unit: VW = cv, Mercedes = kW |
| F2 > 0.12 in 10 rows (Oroch, Duster, MINI JCW, Ferrari 296) | reported in N/(m/s)²; divided by 3.6² |
| Wrong PRR80 (Duster) | PRR80 column removed: it is derived from F0/F2 |
| F1 always 0 | removed |
| Displacement "Elétrico", "N.A.", "1.798" or empty | electric = 0; "1.798" = 1798; empty uses the engine name ("2.0-16V" = 2000, GAC GS4) |
| Honda reported 60 (Ah of the 12 V battery) as kWh | battery = 0 for every combustion car |
| Battery missing in 57 homologations | filled from `complemento_baterias.csv`; low confidence or no source → `bateria_estimada = True` (no source uses the powertrain median) |
| LCVM with spaces, line breaks, "N.A.", "Isento", "xxxx" or a corrupted number (Tank 300) | trimmed; accepts `LC12233`, `19437`, `10945/24`, `SL64402`; anything else becomes empty (118 homologations without LCVM) |
| "#N/A", "#VALUE!", "\", "-", "NA" | empty |
| 3 rows without F0/F2/mass/MJ/km | removed |
| Versions with identical data (same homologation), including across brands (Stellantis vans) | a single row; all of them listed in `versoes` |

## Columns

Column names are in Portuguese, as in the code.

**Identification** (not used by the model)

| column | description |
|---|---|
| `lcvm`, `nome_homologado` | LCVM number and homologated name |
| `marca`, `modelo` | brand and model of the first version in the group |
| `versoes` | every version (brand + model + version) that shares the homologation |
| `n_versoes` | how many versions |
| `grupo_cv` | BRAND MODEL without variant suffixes (4X2/4X4, AT/MT, DIESEL, FLEX, 4M, (MOD. 26), trim level); used as the group in cross-validation (258 groups). Different bodies (Onix × Onix Plus) stay separate |

**Inputs**

| column | unit / values |
|---|---|
| `propulsao` | powertrain: Combustão, Híbrido, Plug-in, Elétrico |
| `combustivel` | fuel: gasolina, flex, diesel, eletrico |
| `categoria` | PBEV category (SC, C, M, G, EXG, SUVC, SUVG, PIC, CL…) |
| `categoria_proconve` | PL, CL, CL1, CL2, CL3 |
| `massa_om_kg` | curb mass in running order (kg) |
| `classe_inercia_kg` | test inertia class (kg) |
| `pbt_kg` | gross vehicle weight (kg) |
| `f0_n` | road-load coefficient F0 (N) |
| `f2_n_kmh2` | road-load coefficient F2 (N/(km/h)²) |
| `area_m2` | declared area (m²); it is length × width, not frontal area. **Not used by the model** (test: error 7.82% → 7.79% with it) |
| `potencia_kw` | maximum power (kW) |
| `cilindrada_cm3` | displacement in cm³; 0 for electric |
| `transmissao` | transmission: automatica, manual, cvt, dct, dht, direta |
| `n_marchas` | number of gears; empty for CVT/DHT |
| `direcao` | steering: eletrica, hidraulica, eletro-hidraulica |
| `bateria_kwh` | nominal battery capacity (kWh); 0 for combustion; no gaps |
| `bateria_estimada` | True when the battery came from inference or the median (17 hybrids) |

**Targets** (corrected values, the ones on the label; empty when not applicable)

| column | description |
|---|---|
| `mj_km` | average energy consumption = 0.55 × city + 0.45 × highway (every row) |
| `mj_km_urbano`, `mj_km_estrada` | city and highway energy consumption |
| `kml_gasolina_urbano/estrada` | km/l on E22 gasoline |
| `kml_etanol_urbano/estrada` | km/l on ethanol (flex only) |
| `kml_diesel_urbano/estrada` | km/l on diesel |
| `kml_eletrico_eq_urbano/estrada` | equivalent km/l (BEV and PHEV); ≈ 20.29 / MJ/km (exact except for the only flex PHEV: 19.95) |

## Known limitations

- There is no drivetrain (4x2/4x4): that spreadsheet field describes the dynamometer, not the vehicle.
- "Híbrido" mixes mild hybrids (e.g. Mercedes "120 + 10") with full hybrids.
- The unit rule for power without a unit holds for VW and Mercedes; a new brand in that format needs review.
- Mild hybrid batteries come largely from databases (CarExpert, auto-data), not from the manufacturer; the 0.9 kWh of the Mercedes 48 V may be a generic value. The hybrid median (0.9) is pulled down by mild hybrids, so the Lexus UX 300h (full hybrid, no source) is underestimated, and is flagged as estimated.
- The supplement is joined on brand + model + power + mass; if a new PBEV spreadsheet changes these values, the row falls back to the median (and is flagged as estimated).
